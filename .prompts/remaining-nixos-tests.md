В отдельном изменении SpecD закрой оставшиеся программные сценарии из `tests/modules/conditional-module-activation.sh` и `tests/modules/primary-user-hm.sh`:

1. NSS: только `kl.nss.tokens.enable`, без сертификатов — регистрация PKCS#11-модулей на чистом home, без физического токена.
2. Transmission без HM: автоматическая подготовка каталогов, права и запуск для системного пользователя.
3. Pass с HM: импорт тестового GPG-ключа и подготовка хранилища из локального тестового Git-репозитория.
4. Printing3d → gitwatch: запуск с правильным пользователем/каталогом и тестовым remote.
5. Gerrit: запуск с проектным конфигом, credential-файлами и плагинами; проверить совместимость закреплённых версий.
